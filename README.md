# smartpaste

The fastest way to fill out job applications

Click Autofill, or press ⌘V in a single field, and it fills in your answer. 


## Code

The Chrome extension is in `extension/`: how it behaves and why is in
`extension/README.md`, and what every source file does is in
`extension/src/README.md`. The code is TypeScript in `extension/src/`,
built into `extension/dist/` with `npm install && npm run build`; `npm test`
runs everything.
